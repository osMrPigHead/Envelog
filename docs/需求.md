**核心定位：一款以信封记账法为蓝本的预算优先 Android 个人或家庭记账软件**

- 信封管理 ^fc763d
	- 支出必须记到信封里 ^e13a14
	- 打开软件直观看到各个信封的余量 ^b4434e
		- 总余量
		- 当日分配量
		- 富余/不足处理方式（用户选择）
			- 均分到剩余日
			- 作为总富余/不足量单独显示
	- 作为账本分类依据，不设二级分类
	- 仅无账单的信封可删除，其余信封均只能归档，归档后：
		- 信封不展示在主界面
		- 有关预算不参与统计
		- 有关交易仅参与总计统计，不参与预算内统计
	- 信封设置 ^21e9c6
		- 支持不设预算的空信封（退化为常规的分类）
		- 支持把预算细分到每一天 / 每 n 天 / 每周 / 每 n 周
- 记账
	- 支出记账 ^b7bdc9
		- 操作足够简单、快速，确保花钱立马记
		- 必须计入信封
	- 收入记账 ^e445f7
		- 支持计入信封 #todo
	- 转账记账 ^7f8c23
		- 支持修改账户信封额度 #todo
	- 人情往来 ^27d5c2
		- 便捷度让位于清晰度
		- 分清楚“是谁”“借多少”“该还多少”“什么时候还”
		- 支持债务免除
		- 联系人管理
	- 一笔多记
		- 支持把一笔账分开，分别计入不同信封、人情往来
	- 操作细节
		- 金额框内计算 ^42cc10
- 多账户功能
	- 记账时必须选择账户
	- 不支持信用账户 ^569408
	- 支持将信封预算分配到账户 ^3ba703
		- 若启用，在记账选择账户处显示各账户额度
- 标签管理
- 查询与统计
	- 筛选器
		- 按信封筛选
		- 按标签筛选
		- 按账户筛选
		- 按人筛选（人情往来记账）

			- 总资产（包含应收款）
			- 总预算（信封预算之和）

			- 总支出
			- 预算内总支出
			- 总预算
			- 预算剩余量
				- 当日分配量
				- 富余/不足量
- 自动化
	- 周期自动扣款 / 收入
- 多账本功能
	- 支持将 A 账本流水嵌入 B 账本 ^9fa41d
		- 解决“旅游账本”“日常账本”互通问题
		- 支持条件嵌入（筛选器或手动选择）

	- 自部署云
