# Iter-1-测试

本文按被测对象分组列出全部 JVM 单元测试（共 87 个用例，来源为 `app/src/test` 84 个与 `app/src/testDebug` 3 个），每个用例给出输入场景与断言标准。`app/src/androidTest` 下的 4 个 instrumented 用例不属于单测，单独列在第十二节。

## 一、测试基线

1. 断言库为 JUnit4（`org.junit.Assert`），协程用例统一用 `runTest`；数据层用例用 Robolectric 沙箱（`@Config(sdk = [35])`）跑内存 Room 库；instrumented 用例用 `runBlocking` 在设备的真实 SQLite 上跑。
2. 时间基线：查询月份固定为 `2026-10`（`2026-10-01 ~ 2026-11-01`），`today` 固定为 `2026-10-20`，时区固定 `Asia/Shanghai`；除特别说明，日期都落在这个月内。
3. 金额单位是"分"，所有金额断言都是 `Long` 精确值。
4. 数据层用例的数据由 `testing/RoomTestData` 构造：信封 A、B，预算 D1~D3，支出 C1，不存在的信封用 `envelopeId(0xEE)` 一类工厂生成。

## 二、core.time：日期区间与日期扩展

被测对象：`HalfOpenDateSpan`、`ClosedDateSpan`、`LocalDateExtensions`（`untilExclusive`、`untilInclusive`、`countDaysTo`、`next`/`previous`/`nextOrSame`/`previousOrSame`）、`YearMonthExtensions`（`first`、`next`、`contains`、`toHalfOpenDateSpan`）。
测试类：`DateSpanTest`（10 个用例），基线区间 `start = 2026-10-01`、`endExclusive = 2026-11-01`。

| 用例 | 输入与断言标准 |
| --- | --- |
| `untilExclusive_keepsStartAndExclusiveEnd` | `start untilExclusive endExclusive`：`startDate == 2026-10-01`、`endDate == 2026-11-01`，右端保持排他 |
| `untilInclusive_keepsBothBounds` | `start untilInclusive 2026-10-31`：`startDate == 2026-10-01`、`endDate == 2026-10-31` |
| `toClosed_subtractsOneDayFromExclusiveEnd` | 半开区间 `[10-01, 11-01)` 调 `toClosed()`：得到闭区间 `[10-01, 10-31]` |
| `closedToHalfOpen_addsOneDayToInclusiveEnd` | 闭区间 `[10-01, 10-31]` 调 `toHalfOpen()`：得到 `HalfOpenDateSpan(10-01, 11-01)` |
| `closedAndHalfOpen_roundTripInBothDirections` | 半开→闭→半开、闭→半开→闭：两个方向都等于原对象 |
| `countDaysTo_returnsHalfOpenSpanLength` | `10-01 → 11-01` 为 `31`；`10-01 → 10-01` 为 `0`；`11-01 → 10-01` 为 `-31`（取 epochDay 差，允许负值） |
| `yearMonth_toHalfOpenDateSpan_coversWholeMonth` | `YearMonth(2026, 10).toHalfOpenDateSpan()`：等于 `[10-01, 11-01)`，且 `startDate countDaysTo endDate == 31` |
| `yearMonth_firstAndNext_areAdjacentMonths` | `first == 10-01`、`next == YearMonth(2026, 11)`、`next.first.minusMonths(1) == first` |
| `yearMonth_contains_matchesYearAndMonth` | `2026-10` 对 `10-01`、`10-31` 为 true；对 `11-01`、`2025-10-15` 为 false |
| `dateOfWeekHelpers_resolveNearestWeekday` | 以周三 `2026-10-21` 为基准：`next(MONDAY) == 10-26`、`previous(MONDAY) == 10-19`、`nextOrSame(WEDNESDAY) == 当天`、`previousOrSame(MONDAY) == 10-19` |
