# 测试

> 本文概括 `app/src/test/java/cn/osmrpighead/envelog/data/repository/` 下的仓库层单元测试，共 49 个用例，全部位于 `InMemoryEnvelogRepositoryTest`（JUnit4 + `kotlinx-coroutines-test`，使用 `runTest` 与 `Flow.first()`，无 Turbine / Robolectric）。

## 1. 基线数据

用例统一使用 `TestData` 中的常量与工厂方法：

1. `periodStart = 2026-10-01`、`periodEnd = 2026-11-01`，所有区间按左闭右开 `[first, second)` 处理。
2. `TestData.period` 是上述区间的 `StartInRange` 版本；`TestData.overlapPeriod` 是同一区间的 `Overlap` 版本。
3. 信封 `A` / `B`、归档信封 `C`、预算 `A`～`D`、交易 `A` / `B`，以及用于异常路径的 `unknownId`。
4. 预算默认区间为 `[2026-10-01, 2026-11-01)`，金额 100000；交易默认发生在区间内。

## 2. DateRangeRule 语义

查询方法的 `DateRange` 由 `period`（查询区间）与 `rule` 组成；预算是否命中由 `DateRange.judge(budget 起止)` 决定。

| 规则 | 命中条件 |
| --- | --- |
| `StartInRange` | 预算起点落在查询区间内 |
| `EndInRange` | 预算终点落在查询区间内 |
| `Overlap` | 预算与查询区间有交集，仅首尾接触不算 |
| `MajorityOverlapFallbackStart` | 重叠天数大于预算天数的一半时命中；恰好一半时回退到 `StartInRange` |
| `MajorityOverlapFallbackEnd` | 重叠天数大于预算天数的一半时命中；恰好一半时回退到 `EndInRange` |

补充约定：

1. 单日判断（`observeTransactions`、`observeExpenditureEnvelopeAllocations`、`DateRange.contains(date)`）只按半开区间判断，不使用 `rule`。
2. `observeBudgets` 与 `clearBudget` 都经过 `DateRange.judge`，因此两者都受 `rule` 影响，同一批数据换 `rule` 会得到不同的结果集。

### 3.2 Budget

| 用例 | 断言点 |
| --- | --- |
| `observeBudgets_filtersByEnvelopeAndStartInRange` | `StartInRange` 与信封过滤叠加；起点等于区间终点不命中 |
| `observeBudgets_filtersByEndInRangeRule` | `EndInRange`：终点在区间内命中，等于区间终点、早于起点、晚于终点均不命中 |
| `observeBudgets_filtersByMajorityOverlapFallbackStart` | 多数重叠命中；恰好一半回退到 `StartInRange`；不足一半时即使包含整个查询区间也不命中 |
| `observeBudgets_filtersByMajorityOverlapFallbackEnd` | 多数重叠命中；恰好一半回退到 `EndInRange`；不足一半时不命中 |
| `observeBudgets_filtersByOverlapRule` | `Overlap`：相交命中（含包住查询区间），首尾恰好接触不命中 |
| `setBudget_createsBudget` | 创建的预算字段与入参一致，并可被区间查询取到 |
| `setBudget_allowsAdjacentPeriodsAndRejectsOverlaps` | 首尾相邻允许；部分重叠、与原预算区间相同、起点早于原预算且与之重叠均抛 `BudgetOverlap`；其他信封同区间允许 |
| `setBudget_rejectsUnknownEnvelope` | 未知信封抛 `NoSuch.Envelope` |
| `setBudget_rejectsPeriodContainingExistingBudget` | 新区间完整包含已有预算时抛 `BudgetOverlap`，已有预算未被修改 |
| `setBudget_allowsPeriodTouchingExistingStart` | 新区间终点等于已有预算起点时允许创建 |
| `setBudget_updatesAmountById` | 按 id 更新金额 |
| `setBudget_rejectsUnknownBudgetId` | 未知 id 抛 `NoSuch.Budget` |
| `clearBudget_removesBudgetById` | 按 id 删除并返回被删除的预算 |
| `clearBudget_rejectsUnknownBudgetId` | 未知 id 抛 `NoSuch.Budget` |
| `clearBudget_removesOverlappingBudgetsOnly` | `Overlap` 下删除相交预算，保留首尾相接的预算 |
| `clearBudget_clearsOnlyGivenEnvelope` | 只删除指定信封的预算，其他信封预算保留 |
| `clearBudget_removesBudgetContainingRange` | 包住查询区间的预算同样被删除 |
| `clearBudget_respectsDateRangeRule` | 同一批预算分别用 `StartInRange` 与 `Overlap` 调用，删除结果不同 |
