## 记账

### 支出

- 点击信封记支出
	- 信封显示在主页上
- 选择账户
- 输入金额
- 选择标签或输入备注（可选）
	- 不能成为单独的一步，整合入输入金额步
- 确认

最少操作次数：4 步

### 人情往来

- 点击主页人情往来记账图标（人情往来记账让位于信封支出记账，可能需要滚动列表）
- 选择账户
- 选择类型（如借出、借入）
- 选择相关联系人及分配规则
- 输入金额
	- 可能包含多项（借出多少、应还多少）
- 选择标签或输入备注（可选）
- 输入到期日（可选）
- 确认

最少操作次数：6+1 步

### 收入

- 点击主页收入记账图标
- 选择账户
- 输入金额
- 选择标签或输入备注（可选）
- 归入信封（可选）
	- 是单独的一步，可以跳过
- 确认

最少操作次数：5+1 步

### 转账

- 点击主页转账记账图标
- 选择转出账户
- 选择转入账户
- 输入金额
- 选择标签或输入备注（可选）
- 确认

最少操作次数：5+1 步

## 信封预算管理

### 新建信封

- 点击主页管理信封
- 点击顶部新建信封
- 设置信封（同一页内）
	- 命名
	- 选择信封类型（预算/非预算信封）
	- 设置预算
		- 快速设置：点击按钮打开 BottomSheet，选择按日设置（每 N 日 X 元，N 使用系统数字键盘、最大为目标区间天数）/ 按周设置（每周选定星期区间 X 元）/ 按月设置（整月金额 X 元）；目标区间默认整月，按日/按周可调整，按月禁用；按日/按周末段不足一个完整周期时暂直接丢弃
		- 已有预算与目标区间重叠时，选择覆盖或取消；覆盖会删除与目标区间相交的旧预算
		- 详细设置：选择日期并设置预算 / 设置周期总预算后按权重分配
		- 设置不同账户额度 / 比例（可选）
	- 确认

### 信封管理

- 排序信封
- 设置信封
- 归档 / 删除信封
	- 仅空信封可直接删除
