## 记账

### 支出

[[需求#^b7bdc9]]

- 点击信封记支出
	- 信封显示在主页上
- 选择账户
- 输入金额
- 选择标签或输入备注（可选）
	- 不能成为单独的一步，整合入输入金额步
- 确认

最少操作次数：4 步

### 人情往来

[[需求#^27d5c2]]

- 点击主页人情往来记账图标（人情往来记账让位于信封支出记账，可能需要滚动列表）
- 选择账户
- 选择类型（如借出、借入）
- 选择相关联系人及分配规则
- 输入金额
	- 可能包含多项（借出多少、应还多少）
- 选择标签或输入备注（可选）
- 输入到期日（可选）
- 确认

最少操作次数：6+1 步

### 收入

[[需求#^e445f7]]

- 点击主页收入记账图标
- 选择账户
- 输入金额
- 选择标签或输入备注（可选）
- 归入信封（可选）
	- 是单独的一步，可以跳过
- 确认

最少操作次数：5+1 步

### 转账

[[需求#^7f8c23]]

- 点击主页转账记账图标
- 选择转出账户
- 选择转入账户
- 输入金额
- 选择标签或输入备注（可选）
- 确认

最少操作次数：5+1 步

## 信封预算管理

### 新建信封

[[需求#^21e9c6]] [[需求#^3ba703]]

- 点击主页管理信封
- 点击顶部新建信封
- 设置信封（同一页内）
	- 命名
	- 选择信封类型（预算/非预算信封）
	- 设置预算
		- 快速设置：每日预算统一 / 设置周期总预算
		- 详细设置：选择日期并设置预算 / 设置周期总预算后按权重分配
		- 设置不同账户额度 / 比例（可选）
	- 确认

### 信封管理

- 排序信封
- 设置信封
- 归档 / 删除信封
	- 仅空信封可直接删除
