## 基本原则与描述方式

- 一级项目为表名 / 数据类名称
	- 二级项目为字段
- 金额全部以 `long` 存为整数分
	- 发生额类金额约束为非负数，流动方向由单独字段指定
	- 余额类金额有符号
- 日期约定采用半开区间 `[startDate, endDate)` 存储
- 使用的类型不直接对应 Kotlin 或 SQL 中的数据类型，仅作为描述的参考

## 模型

- Envelope
	- id: uuid
	- name: string
	- isBudgeted: bool
	- archived: bool
- Budget
	- id: uuid
	- envelope->Envelope
	- startDate: date
	- endDate: date
	- amount`(>0)`: long
- Transaction
	- id: uuid
	- type: enum(Expenditure,)
	- dateTime: dateTime
	- amount`(>0)`: long
- ExpenditureEnvelopeAllocation
	- transaction->Transaction
	- envelope->Envelope
	- amount`(>0)`: long

## 约束与计算约定

- Envelope
	- ExpenditureEnvelopeAllocation 中存在到 Envelope 的引用时，不允许删除而仅允许归档（将 archived 设为 true）
- Budget
	- 规定 Envelope 在 `[startDate, endDate)` 区间内的预算
	- 区间不可重叠
	- 若 Budget 区间横跨两个月
		- Envelope 作月度结算时，按用户设置判断所属月份
		- 查看 Envelope 预算详情时，日期重叠即显示
	- 生成 Budget 列表时，仅生成当月列表
	- 零预算日不应计入 Budget
